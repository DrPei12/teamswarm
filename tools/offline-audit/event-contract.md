# Input contract
A JSON array of TeamSwarm event envelopes: {sequence: positive integer,id: string,teamId: string,runId: string|null,workId: string|null,attemptId: string|null,type: string,data: object,createdAt: ISO timestamp}. sequence is global order. The same event id may be repeated identically by cursor replay; deduplicate it. Conflicting duplicate ids must fail. Sort by sequence. Unknown event types are ignored by analyzers. work.running begins attempt occupation; work.submitted/accepted/failed/interrupted/yielded ends it; work.stopping and recovery_required do not confirm an end. exchange.headers_delivered is headers only, exchange.read is actual delivery of listed messageIds, exchange.closed is an initiator claim. Counts must keep these concepts distinct. A synthetic sample is supplied in `sample-events.json`.

All nine fields are required even when their value may be null. Validation precedes team filtering. The parser's timestamp profile and error protocol are specified in the [usage documentation](README.md).
