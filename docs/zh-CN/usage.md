# 团队使用

[第一个项目](getting-started.md) · [运行架构](architecture.md) · [English](../en/usage.md)

## 讨论与委托

Host 是团队持续的用户对话入口。说明目标、相关文件和验收条件，成员执行期间仍可继续讨论。Host 根据资源目录及项目需要创建或复用成员，并选择执行资源。

## 查看工作线程

工作线程组织同一责任的执行尝试、消息和交付。打开成员或工作详情查看实际活动。只读追问用于了解已有工作；“继续修改”提出下一轮变更，并产生新的交付。

成员可以在执行中互相提问、交流信息。协作视图显示已记录的活动，未回答的请求与未完成的承诺继续保存在团队状态中。

## 检查成果

打开成果，查看对应版本并按需下载。后续交付产生新版本，原版本继续保留。根据任务要求核对具体检查，例如入门教程中的命令及输出。

小范围可逆工作可以采用自检交付。需要独立验收时，明确指定另一个审查者，以及它必须针对所提交版本执行的检查。系统保存该版本的审查与接受记录。

## 调整方向

在 Host 对话中描述要求变化。项目定义与工作保留修订信息，相关任务可针对新的有效定义更新或重跑。通过项目历史检查节点，再从其已保存文件创建新分支。快照之外的外部服务及项目文件按各自方式备份。

## 暂停、继续与恢复

使用执行控制暂停或停止工作，等待实际状态收束后再开始有冲突的修改。服务与原生执行失联时，先通过恢复核对结果，再重试。具体方法见[故障排查](troubleshooting.md)。
