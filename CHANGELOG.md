# Changelog

## 0.4.1

- Preserve unsent drafts across browser tabs while offline and after reopening.
- Keep saved drafts visible when delayed refresh or initial-load responses arrive.

## 0.4.0

- Local workspace with persistent team conversations, work threads, project history and versioned deliverables.
- Native adapters for Codex, Claude Code, Grok, Pi, DeepSeek Harness and OpenCode.
- Per-member and per-work execution resources, with provider connections and configuration snapshots.
- Windows x64 installer, with Linux x64 and macOS Apple Silicon source build targets.
- Cross-platform data locations, desktop keyring integration, native process identity and reboot-aware recovery.
- English and Simplified Chinese installation, onboarding, usage and developer documentation.
- Apache-2.0 license and bundled third-party notices.

Installation formats and signing status are listed in [Platform support](docs/en/platforms.md).
