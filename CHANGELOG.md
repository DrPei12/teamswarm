# Changelog

## 0.5.0

- Assign explicit file ownership and reject overlapping writes and stale edits.
- Reuse delegated responsibilities and preserve unpublished files when continuing work.
- Prepare native check environments on demand and require fresh evidence after review instructions change.
- Adopt selected discussion-branch ideas into mainline documents with user authorization and recorded sources.
- Separate team progress from completed deliverables and preserve history layout and reading position.
- Preserve existing task permissions during upgrades and retain completed deliveries when a workspace snapshot is unavailable.
- Avoid repeating the current Host request in recent context.
- Update Electron and service/build dependencies, including the bundled npm runtime.

## 0.4.3

- Update the bundled npm runtime to use ip-address 10.7.4.
- Load Pi project instructions from the task workspace.
- Configure Pi and OpenCode output limits and context windows in execution resources.
- Preserve model limits and Pi reasoning effort when editing and exporting resources.
- Apply OpenCode output limits above 32000 tokens and forward explicit Pi Chat Completions reasoning effort.

## 0.4.2

- Remove the vulnerable numeric formatter from desktop build dependencies.

## 0.4.1

- Preserve unsent drafts across browser tabs while offline and after reopening.
- Keep saved drafts visible when delayed refresh or initial-load responses arrive.

## 0.4.0

- Local workspace with persistent team conversations, work threads, project history and versioned deliverables.
- Native adapters for Codex, Claude Code, Grok, Pi, DeepSeek Harness and OpenCode.
- Per-member and per-work execution resources, with provider connections and configuration snapshots.
- Windows x64 installer, with Linux x64 and macOS Apple Silicon source build targets.
- Cross-platform data locations, desktop keyring integration, native process identity and reboot-aware recovery.
- English and Simplified Chinese installation, onboarding, usage and developer documentation.
- Apache-2.0 license and bundled third-party notices.

Installation formats and signing status are listed in [Platform support](docs/en/platforms.md).
